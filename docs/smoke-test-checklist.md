# Riverbend Workshop Smoke Test Checklist

Use this checklist after each milestone update. The player should be able to complete it without typing notes.

1. Load the app and confirm the playable field is visible without page scrolling.
2. Select each tool and confirm the selected state differs from the recommended state.
3. In Survey, choose an excavation area and confirm guidance updates.
4. In Excavation, brush find #1 until it is lift-ready, then lift it.
5. Use Seed tray to recover the representative set.
6. Open Examination and clean/rotate the selected find until an observation appears.
7. Open Join and confirm at least one physical join with Test join.
8. Group cooking, textile, closure, and disturbance evidence.
9. Open Reconstruction and place supported zones only after matching evidence is grouped.
10. Open Interpretation, choose each explanation, and confirm confidence and contradictions update.
11. Start Fieldwork variation and confirm positions/seed label change while using the same evidence logic.
12. Save, reload, and confirm the restored state is not overwritten by the default opening state.
13. Check desktop, tablet, and mobile widths for no required browser-page scrolling during active play.
14. On mobile, open the Context drawer and confirm selected find, storage, confidence, and quick navigation are reachable.
